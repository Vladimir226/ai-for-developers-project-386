# Глоссарий

Термины проекта «Запись на звонок» (Book-a-Call). Канонические решения —
[`bmad-output/architecture.md`](bmad-output/architecture.md) (ADR-001…010);
однострочные сводки — [`bmad-output/decision-log.md`](bmad-output/decision-log.md).

| Термин               | Определение                                                                                                                                                |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Слот (Slot)          | Опубликованный владельцем дискретный интервал времени; равен одному бронируемому звонку. См. ADR-008.                                                      |
| Бронь (Booking)      | Закрепление слота за посетителем: имя, контакт, необязательный комментарий. Антидубль — UNIQUE `slot_id` на уровне БД. См. ADR-008.                        |
| Владелец             | Единственный управляющий пользователь (single-owner, без auth — ADR-003).                                                                                  |
| Свободный слот       | Слот без связанной брони, целиком лежащий в будущем (`view=free`).                                                                                         |
| `view=free\|all`     | Параметр `GET /api/v1/slots`: `free` (дефолт) — только свободные будущие; `all` — все интервалы, включая забронированные и прошедшие (для админ-страницы). |
| Контракт (TypeSpec)  | Единственный источник истины API: каталог `contract/`. Из него генерируются OpenAPI-спецификация, типы SDK и Zod-схемы. См. ADR-010.                       |
| OpenAPI-спецификация | `openapi.yaml`; генерируется из TypeSpec, коммитится в репозиторий.                                                                                        |
| SDK                  | Сгенерированный клиент (`openapi-typescript` + `openapi-fetch`) в `src/generated/`; единственный способ обращения UI к API.                                |
| Конверт ошибок       | Единая форма ошибки API: `{"error": {"code", "message", "details"?}}`; коды SCREAMING_SNAKE_CASE, сообщения на русском. См. ADR-005.                       |
| WAL                  | Write-Ahead Logging — режим SQLite, допускающий чтение во время записи.                                                                                    |
| Шов тестирования     | Уровень, на котором пишутся тесты: шов 1 — API-интеграция (Vitest, основной), шов 2 — Playwright e2e, шов 3 — unit чистых функций.                         |
