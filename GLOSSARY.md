# Глоссарий

Термины проекта «Запись на звонок» (Book-a-Call). Канонические решения —
файлы [`docs/adr/`](docs/adr/README.md) (ADR-0001…0011); однострочные сводки —
[`bmad-output/decision-log.md`](bmad-output/decision-log.md); исторический
архитектурный документ — [`bmad-output/architecture.md`](bmad-output/architecture.md).

| Термин                          | Определение                                                                                                                                                                                                                                                                                  |
| ------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Владелец                        | Единственный управляющий пользователь (single-owner, без auth — [ADR-0003](docs/adr/0003-single-owner-no-auth.md)): задаёт типы событий и рабочие часы, управляет бронями.                                                                                                                   |
| Гость                           | Посетитель, который бронирует звонок без регистрации и аккаунта. Канонический термин вместо «посетитель».                                                                                                                                                                                    |
| Тип события (Event Type)        | Вид встречи, который задаёт владелец: название, описание и длительность в минутах. Длительность типа задаёт длительность слота и шаг стартов. См. [ADR-0011](docs/adr/0011-derived-slots-from-event-types.md).                                                                               |
| Рабочие часы (Working Hours)    | Настройки доступности владельца по дням недели (дефолт Пн–Пт 09:00–18:00, Сб–Вс выходные) в зоне `APP_TZ`; слоты вычисляются только внутри них. См. [ADR-0011](docs/adr/0011-derived-slots-from-event-types.md).                                                                             |
| Вычисляемый слот (Derived Slot) | Свободное окно записи «тип события + старт», вычисляемое на лету из типов событий, рабочих часов и окна записи; в БД не хранится. Коротко — слот. См. [ADR-0011](docs/adr/0011-derived-slots-from-event-types.md).                                                                           |
| Бронь (Booking)                 | Закрепление интервала за гостем: тип события, старт, имя, контакт, необязательный комментарий. Интервалы двух броней не пересекаются, включая разные типы. См. [ADR-0011](docs/adr/0011-derived-slots-from-event-types.md).                                                                  |
| Окно записи                     | Период, открытый гостю для брони: 14 календарных дней начиная с сегодняшнего дня (зона `APP_TZ`). См. [ADR-0011](docs/adr/0011-derived-slots-from-event-types.md).                                                                                                                           |
| Предстоящая бронь               | Бронь, которая ещё не завершилась в момент просмотра: конец позже текущего момента. Отображается у владельца в админке и на публичной странице «Предстоящие записи». См. [ADR-0011](docs/adr/0011-derived-slots-from-event-types.md), [ADR-0012](docs/adr/0012-public-upcoming-bookings.md). |
| Контракт (TypeSpec)             | Единственный источник истины API: каталог `contract/`. Из него генерируются OpenAPI-спецификация, типы SDK и Zod-схемы. См. [ADR-0010](docs/adr/0010-contract-first-typespec.md).                                                                                                            |
| OpenAPI-спецификация            | `openapi.yaml`; генерируется из TypeSpec, коммитится в репозиторий.                                                                                                                                                                                                                          |
| SDK                             | Сгенерированный клиент (`openapi-typescript` + `openapi-fetch`) в `src/generated/`; единственный способ обращения UI к API.                                                                                                                                                                  |
| Drift-check                     | Проверка синхронности контракта и артефактов: регенерация + `git diff --exit-code -- src/generated/` в `make lint`. См. [ADR-0010](docs/adr/0010-contract-first-typespec.md).                                                                                                                |
| Конверт ошибок                  | Единая форма ошибки API: `{"error": {"code", "message", "details"?}}`; коды SCREAMING_SNAKE_CASE, сообщения на русском. См. [ADR-0005](docs/adr/0005-api-error-envelope.md).                                                                                                                 |
| WAL                             | Write-Ahead Logging — режим SQLite, допускающий чтение во время записи.                                                                                                                                                                                                                      |
| Шов тестирования                | Уровень, на котором пишутся тесты: шов 1 — API-интеграция (Vitest, основной), шов 2 — Playwright e2e, шов 3 — unit чистых функций.                                                                                                                                                           |
