# Дизайн «Записи на звонок» — направление C «Спокойный шалфей»

Утверждён владельцем 07.11.2026 (тикет #13). Источник стиля — референс
[cal.com](https://cal.com/) «по мотивам» + референс-макеты владельца; выбранное
направление — тёплая «бумажная» база с приглушённым шалфейным акцентом.

## Состав

| Путь                               | Что это                                                             |
| ---------------------------------- | ------------------------------------------------------------------- |
| `moodboards/moodboard-{a,b,c}.png` | Три направления; **утверждено C**. `board-*.html` — исходники арбор |
| `prototype/index.html`             | Публичная страница `/`: календарь 14 дней → слоты дня → форма       |
| `prototype/events.html`            | «Предстоящие события»: подтверждённые брони (+ пустое состояние)    |
| `prototype/admin.html`             | Админка `/admin`: мультиввод интервалов + брони с отменой           |
| `screenshots/*.png`                | Скриншоты: страницы × состояния × desktop/mobile                    |

Прототип самодостаточен (Tailwind 4 browser-build + Google Fonts Manrope) — для
просмотра нужен интернет. Это одноразовый артефакт: продакшен-страницы (#5, #7,
#8) переносят токены ниже в свой `globals.css`, а не подключают этот файл.

Страница `events.html` («Предстоящие события», список подтверждённых броней)
добавлена по решению владельца на дизайн-этапе: в спеке #1 и API-контракте её
пока нет — под неё нужен отдельный тикет (роут + способ выборки «своих» броней).

## Дизайн-токены (Tailwind 4 `@theme`)

| Токен       | Значение  | Роль                                          |
| ----------- | --------- | --------------------------------------------- |
| `paper`     | `#FAF9F6` | фон страницы                                  |
| `card`      | `#FFFFFF` | поверхности карточек                          |
| `line`      | `#E7E3DA` | границы 1px, разделители                      |
| `ink`       | `#37352F` | основной текст (тёплый уголь, не чёрный)      |
| `muted`     | `#8A857B` | вторичный текст                               |
| `faint`     | `#B7B1A4` | плейсхолдеры, неактивные иконки               |
| `sage`      | `#5F8575` | акцент: кнопки, ссылки, статусы «Свободен»    |
| `sage-deep` | `#4C6F60` | hover акцента                                 |
| `sage-soft` | `#EDF3F0` | подложки выделения, бейджи «Свободен»         |
| `clay`      | `#C4714B` | только ошибки и деструктивные действия        |
| `clay-deep` | `#A85A38` | текст ошибок                                  |
| `clay-soft` | `#FAF1EC` | подложка алертов ошибок                       |
| `warmgray`  | `#F3F1EC` | нейтральные бейджи («Прошёл», «Забронирован») |

- Шрифт: **Manrope** (400–800), fallback system-ui; времена — всегда
  `font-variant-numeric: tabular-nums`.
- Радиусы: 12px контролы и карточки (`rounded-xl`), 20px крупные секции
  (`rounded-2xl`), пилюли статусов `rounded-full`.
- Тени: одна едва заметная `0 1px 3px rgba(55,53,47,.04)` на карточках; глубину
  держат границы, не тени.
- Плотность: воздушная (шаг 10–14px), sticky-левая колонка на обеих страницах.

## Правила из прототипа

- Время: везде с явным поясом — «MSK (UTC+3)» (ADR-009: хранение UTC, показ в
  `APP_TZ`, ru-RU).
- Ошибки API → человекочитаемые алерты: `SLOT_ALREADY_BOOKED` = «Это время
  только что заняли…» (публичная), `SLOT_OVERLAP` = «Интервалы пересекаются…»
  со списком конфликтов (админка). Палитра clay — только для ошибок.
- Статусы интервалов: «Свободен» (sage), «Забронирован» и «Прошёл»
  (нейтральный warmgray) — бронь не ошибка.
- Состояния прототипа переключаются кнопками в пунктирной полосе сверху —
  это элемент прототипа, в продакшен не переносится.
- Мобильный (390px): одна колонка, сетка слотов 2 колонки, строки мультиввода
  не переносятся по горизонтали, хедер в одну строку.
